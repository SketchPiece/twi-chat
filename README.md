# TwiChat v0.4

June 2019. The first version that worked: Express with EJS templates, sessions stored in MongoDB, and one shared chat room over Socket.io.

This branch keeps an early version of TwiChat as it was. The latest version, and the story of how the app grew from here, is on the [`master`](https://github.com/SketchPiece/twi-chat) branch.

Written by hand in 2019, before AI tools. Secrets in the config are placeholders; set your own before running it.
